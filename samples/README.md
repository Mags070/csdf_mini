# Sample Images

Place sample images here for testing ImageShield.

## Recommended Test Files

1. **Original JPEG** — A normal photograph taken with a camera (contains EXIF data).
2. **Edited JPEG** — The same photograph after editing in any image editor and re-saving.
3. **PNG Image** — Any PNG screenshot or graphic.
4. **No-EXIF Image** — A JPEG saved without metadata (e.g., downloaded from the web).
5. **Identical Copy** — A byte-for-byte copy of any test image (use `copy` command).

## Creating Test Images

```bash
# Create an identical copy (Windows)
copy original.jpg identical_copy.jpg

# Create a modified version
# Open original.jpg in Paint, make a small edit, and Save As modified.jpg
```

## Important

- Use only images you own or have explicit permission to use.
- Do not include copyrighted images in version control.
